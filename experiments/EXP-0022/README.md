# EXP-0022

EXP-0021 proved that the assisted boss-guide reward preferred zero-contact
timeouts over unsuccessful practice. EXP-0022 changes only the two conflicting
survival terms: player damage and death receive zero guide reward. Boss-only
damage, boss kill, real level completion, A8 transfer, player20 assistance,
seed-selection rules, PPO budget, and bootstrapped 500-turn cutoff remain fixed.

The experiment tests whether an outcome-aligned acquisition reward preserves
the parent's boss contact and advances Death Metal phases. It does not count as
normal-start Zone 2 evidence. A pass authorizes assistance contraction and
backward curriculum expansion; a failure authorizes a separately declared
teacher-KL retention test rather than another simultaneous reward or
architecture change.
