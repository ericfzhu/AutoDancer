# EXP-0021

This is the executable successor to statically rejected EXP-0020. It changes exactly the guide reward's combat-event scope from all enemies to authoritative boss entities. The legal player-health-only curriculum, source policy, A8 transfer, seed disclosure rules, budget, and gameplay-based decision gate remain fixed.

The experiment is deliberately a reverse-curriculum acquisition stage. Even a passing result is evidence only for a legal Death Metal finishing skill with extra player health. It must be expanded backward and then evaluated from unassisted normal All Zones starts before it can satisfy the Zone 2 goal.
